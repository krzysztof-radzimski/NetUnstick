NetUnstick — Support

Run a check

Click Run diagnostics. Checks observe the connection; they do not change network settings. Open Network details to see each result. You can cancel an operation in progress.

Two editions

The App Store edition checks the network path, DNS, an internet connection, Bonjour and a chosen device. It does not inspect system routes or VPN configuration and cannot repair them. The Developer ID edition adds system diagnostics and individually confirmed repairs.

Get useful help

Reproduce the issue, run diagnostics and preview the relevant session in Activity. Share a redacted report with your administrator or use the support contact on the app distribution page. Include what failed and when; omit private network details.

Narrow changes only

NetUnstick does not implement a VPN, change FortiClient/FortiGate policy, disable protections, flush all routes or reboot. Do not disable a firewall or managed security policy to obtain a green status. Ask your network administrator about managed VPN settings.
